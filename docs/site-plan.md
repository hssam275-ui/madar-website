## 1. الهدف

## 4. هيكل الموقع المستهدف

```
/                         الرئيسية (عرض القيمة، أعمال مختارة، خدمات، خطوات، FAQ، نموذج)
/services/                فهرس الخدمات  ← جديد
  /services/media/        الإنتاج الإعلامي والفيديو (موجود)
  /services/photography/  التصوير الفوتوغرافي والدرون  ← بعد تأكيد الخدمات
  /services/podcast/      إنتاج البودكاست والاستوديو   ← بعد تأكيد الخدمات
  /services/content/      صناعة المحتوى وإدارة الحسابات ← بعد تأكيد الخدمات
  /services/print/        الطباعة والهدايا الدعائية (موجود)
  /services/events/       تغطية وتجهيز الفعاليات        ← جديد
/work/                    معرض الأعمال بالتصنيفات  ← جديد (حاليًا قسم في الرئيسية)
  /work/<slug>/           دراسة حالة: التحدي، ما نفذناه، الفيديو، النتيجة
/sectors/                 القطاعات: حكومي وبلديات، جمعيات، عقار، مطاعم، عيادات ← بعد التأكيد
/about/                   من نحن (بعد معلومات مؤكدة)
/taif/                    مدار في الطائف: صفحة محلية حقيقية للخدمات ومنطقة الخدمة ← جديد
/blog/                    المدونة
/contact/ أو /#contact    طلب عرض سعر + واتساب
/en/...                   نفس الهيكل بالإنجليزي للصفحات الأساسية (ليس كل المقالات)
/404                      صفحة خطأ بروابط مفيدة ← جديد
```

كل صفحة خدمة تحتوي: إجابة مختصرة، ما الذي تشمله الخدمة، أعمال حقيقية من نفس الفئة، خطوات العمل، أسئلة شائعة (FAQPage)، دعوة عرض سعر + واتساب، روابط لمقالات ذات صلة.

## 8. التحويل (Conversion)

- دعوة واحدة واضحة في كل شاشة: "اطلب عرض سعر"، وثانوية "واتساب".
- نموذج قصير: الاسم، الجوال/البريد، نوع الخدمة، وصف مختصر، الموعد (الميزانية اختيارية).
- عرض أعمال حقيقية من نفس الخدمة بجانب كل دعوة (الدليل يبيع).
- صفحة شكر بعد إرسال النموذج + رسالة واتساب جاهزة.
- قياس مجاني: Google Search Console + أحداث بسيطة (نقرات واتساب وإرسال النموذج) عبر Cloudflare Web Analytics أو GA4 المجاني، بعد موافقة المستخدم.
